## Original item inventory

1. Envelope Assemblies: export one PDF containing every assembly, one assembly
   per page, with the SVG drawing and material table; launch from the existing
   `aria-label="Assembly actions"` menu.
2. Public Assembly viewer: show left-side thickness dimension lines and labels
   to anonymous users, but do not allow editing; match Apertures read-only
   behavior.
3. Apertures Installs modal: scale the SVG to show the complete aperture and all
   overlay elements with padding; no clipping.
4. App-wide small equal-width `SegmentedControl`: make hover visibly clickable
   and add delayed, viewport-safe shared tooltips.
5. App-wide expandable `ReportTable`: fix the expanded-row background/accent
   border seam and corner notches shown on Envelope → Materials.
6. Diff modal: replace raw path output with a human-readable diff; improve
   default width, resizing, overflow handling, and modal action consistency.
7. Version management: add a dedicated management surface with rename and
   delete; add last-edited date/time to the existing version list.
8. Documentation → Envelope: put fully N/A materials in one bottom section for
   logged-in users; hide them entirely from anonymous users.
9. Overview Roadmap: replace left-rail `X`/`O` status glyphs with `Done` and
   `To-Do`; remove the duplicate status badge beside the title.
10. Envelope Assembly header: replace the oversized condensation status chip
    with a compact text label aligned to Total thickness and Thermal.
11. Envelope Assembly header: hide the entire Moisture label/action from
    anonymous users until the feature is fully supported and tested.
12. 3D Model viewer: color windows by shading factor, with Summer and Winter
    sub-options.
